## Installing

Copy the `atmosphere` directory onto the root of the SD card,
then restart the game. The cheats appear in Atmosphere's cheat
menu (`ZL` + `ZR` + `Down` on the home menu, or any cheat
manager overlay).

The `.nxc` beside the `.txt` is a trainer pack for the
NXCLoader overlay, which gives the same cheats a UI with
sliders and value readouts. The two can be installed
together.

The filename is the build id. If the game updates, `671DB2118A8BBCB5`
no longer matches and nothing loads: that is the safety, not a
bug.
